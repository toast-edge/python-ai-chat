# 测试文档

这是一个用于测试RAG功能的示例文档。

## 产品信息

产品名称：智能助手
版本：2.0.0
发布日期：2024年1月15日

## 功能特性

1. 自然语言交互
2. 多轮对话支持
3. 知识库查询
4. 任务自动化
5. 个性化设置

## 使用方法

- 启动程序：运行 `python ai_chat_with_api.py`
- 帮助信息：输入 `help` 或 `帮助`
- 退出程序：输入 `quit` 或 `退出`
- 保存对话：输入 `save` 或 `保存`

## 常见问题

Q: 如何切换AI模型？
A: 输入 `switch` 命令，然后选择要使用的AI服务。

Q: 如何启用RAG功能？
A: 输入 `rag` 命令，然后选择 `enable` 或 `开启`。

Q: 如何添加文档到RAG？
A: 输入 `rag` 命令，然后选择 `add` 或 `添加`，输入文档路径。
