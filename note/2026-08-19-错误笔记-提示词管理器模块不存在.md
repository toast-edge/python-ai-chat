# 错误笔记：提示词管理器模块不存在，创建简化版本

> 记录时间：2026-08-19
> 触发场景：`python .\run_ai_chat.py` 启动时打印该警告

---

## 一、原始提示

```
⚠️ 提示词管理器模块不存在，创建简化版本
```

## 二、根本原因

[ai_chat_with_api.py](file:///f:/work-space/AI_GROUP/python-ai-chat/src/ai-api/ai_chat_with_api.py) 的 `AIChatter.setup_prompt_manager()` 里执行：

```python
from prompt_manager import PromptManager
self.prompt_manager = PromptManager()
```

但 `ai-api` 目录下**根本没有 `prompt_manager.py` 这个文件**，于是触发 `ImportError`，被 `except ImportError` 捕获后打印警告并把 `self.prompt_manager` 置为 `None`，程序降级为「只用 config 里的 system_prompt」。

### 附带发现：方法被重复定义

`setup_prompt_manager` 在类里被定义了两遍：
- 第 431 行（真正应该使用的版本，成功时会打印「✅ 提示词管理器初始化成功」）
- 第 674 行（重复副本，打印「创建简化版本」）

Python 类中后定义的同名方法会覆盖前者，所以实际跑的是第 674 行那个，你才会看到「创建简化版本」这条文案。两处本质都是同样的 fallback 逻辑，属于复制粘贴/合并残留。

## 三、修复

1. **新建缺失模块 `prompt_manager.py`**，实现 `PromptManager` 类及 `PromptTemplate` 数据类，提供以下 API（被 `ai_chat_with_api.py` 调用）：
   - `get_current_template()`：返回当前模板，无则 None
   - `get_templates()`：全部模板列表
   - `current_template_id`：当前模板 ID 属性
   - `set_current_template(id)`：切换模板，返回是否成功
   - `add_template(name, description, system_prompt, tags)`：新增模板，返回新 ID
   - `search_templates(keyword)`：按名称/描述/标签搜索
   - `get_popular_templates(n)`：按使用次数排序返回热门模板
   - 内置 4 个默认模板（通用助手 / 代码专家 / 翻译助手 / 写作助手），并支持保存到 `prompt_templates.json` 持久化。

2. **删除重复的第二个 `setup_prompt_manager`**（第 674-695 行），只保留第 431 行那个，消除混淆。

## 四、验证

```
python -m py_compile ai_chat_with_api.py prompt_manager.py   # 无语法错误

python -c "import ai_chat_with_api; ai_chat_with_api.AIChatter(config_file='config.json')"
# 输出：✅ 提示词管理器初始化成功
#      🎯 当前响应模式: 流式响应
#      🔍 RAG功能: 已启用
```

警告消失，`prompt_manager` 已正确实例化为 `PromptManager`。

## 五、经验总结 / 避坑要点

1. **模块级/方法内 import 前先确认文件是否存在**：代码 `from xxx import ...` 但对应 `.py` 缺失时，会走 `except ImportError` 的降级分支，功能悄悄失活而非崩溃，容易被忽略。
2. **同名方法后定义覆盖前定义**：类里若出现两个同名方法，只有最后一个生效，前面的成为死代码。合并代码时要注意重复定义。
3. **降级提示要准确**：本例「创建简化版本」其实并没有真的创建任何东西，只是置 None，文案有误导性。修复后由真正实现 + 明确的成功提示取代。
4. **验证要走到真实调用点**：光 import 不够（`from prompt_manager import ...` 是方法内延迟导入），要实例化 `AIChatter` 触发 `setup_prompt_manager()` 才能确认修复。
